Meet VEX before soldering.

The screen below comes from the firmware's shared C++ renderer, and the controls drive the same vex::App state machine the Teensy runs, including debounce, 1.2 s holds, calibration and the two-slot save. Hold QUEST to calibrate, tap the footswitch, then choose a signal.

VEX

Press and hold the controls as on the pedal: tap MODE for tuner, hold MODE to save, tap QUEST for the next goal, hold QUEST to calibrate, hold the footswitch for a new session. The screen is enlarged; this page does not simulate the pedal's physical size.

Practice input

Real audio through the shared detector

The test recording and your Mac's input run through the same block RMS/peak and YIN pitch code the Teensy compiles, at 44.1 kHz. This is Mac audio, not the SGTL5000 line-in path: codec gain, the attenuator and rig noise still need the bench. The periodic injected signal pauses while Mac input is on.

Display stages

Changing stage reboots the simulated device like a re-flash. Stage 2 indicators show the simulated control levels; the real GPIO bench test is still required.

No Teensy CPU, codec, SPI, I²S, electrical noise or EEPROM flash timing is emulated. See docs/LOCAL_DEVELOPMENT.md for what each test proves.
